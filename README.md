# Doble Código

Landing responsive para un equipo de desarrollo de software. Presenta los servicios, el proceso de trabajo y una sección de proyectos.

## Tecnologías

React, Vite y CSS.

## Ejecutar en local

Requiere Node.js 22.12 o posterior.

```sh
npm ci
npm run dev
```

Para generar la compilación de producción, ejecutá `npm run build`.

## Estado del proyecto

La sección de proyectos y los enlaces de contacto tienen contenido provisional. Los datos de contacto se pueden editar en `src/config/site.js` y los proyectos en `src/data/projects.js`.
